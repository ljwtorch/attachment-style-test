# 四类依恋类型测试题库调研与合规建议

更新时间：2026-05-17  
适用场景：面向 C 端网站的“成人亲密关系依恋类型测试”  
目标：做出 `安全型 / 焦虑型 / 回避型 / 混乱型（或恐惧-回避型）` 四类结果，并尽量规避版权、授权与专利风险

## 一、先给结论

如果你要做一个可商业化上线的网站，最稳妥的路线不是直接搬运某个经典量表全文，而是：

1. 用公开理论框架定义四类结果。
2. 参考公开量表的维度结构与评分逻辑。
3. 优先采用许可明确、可复用的开放量表或开放短量表。
4. 对最终上线题目做自主改写，避免逐题照搬原文。
5. 在页面中明确写出“仅供自我探索，不替代临床诊断/心理咨询”。

对你当前需求，我最推荐的产品路径是：

- 结果模型：采用四类结果
  - 安全型 `Secure`
  - 焦虑型 `Preoccupied / Anxious`
  - 回避型 `Dismissing / Avoidant`
  - 混乱型 `Fearful / Disorganized`
- 测量底层：仍然以两个连续维度作为评分基础
  - `依恋焦虑`
  - `依恋回避`
- 呈现方式：前台给用户展示“四类结果”，后台保留二维分数

这条路线的优点是：

- 对用户友好，结果更容易理解和传播。
- 与学术界主流二维模型兼容。
- 后续能扩展成长报告、关系建议、匹配分析。
- 比直接照搬早期四段式原量表更容易做合规改写。

## 二、为什么建议“四类结果 + 二维评分”

公开资料显示，成人依恋研究里常见两条路线：

1. 早期四类型模型  
代表：`Relationship Questionnaire (RQ)`，直接对应四种依恋风格。

2. 后期二维模型  
代表：`ECR / ECR-R / ECR-RS`，核心是“焦虑”和“回避”两个维度。

R. Chris Fraley 的量表说明页明确建议研究者优先用多题目的二维量表，并指出成人依恋更适合被理解为二维空间，而不是严格离散类别。  
来源：<https://labs.psychology.illinois.edu/~rcfraley/measures/measures.html>

这意味着产品上最好的折中方案通常是：

- 用二维题项提升测量稳定性
- 再把二维分数映射成四类结果

一个常见映射示例：

- 低焦虑 + 低回避 = 安全型
- 高焦虑 + 低回避 = 焦虑型
- 低焦虑 + 高回避 = 回避型
- 高焦虑 + 高回避 = 混乱型 / 恐惧-回避型

说明：学术文献中第四类更常见的原始称呼是 `Fearful` 或 `Fearful-Avoidant`。如果产品上要写“混乱型”，建议在文案里注明“对应恐惧-回避倾向”，避免概念混淆。

## 三、重点量表与授权判断

下面按“适合做网站”的角度筛选。

### 1. RQ：Relationship Questionnaire

定位：

- 四段描述，最贴近你要的四类结果输出。
- 很短，适合做原型或结果校准参考。

公开来源：

- Fetzer Institute 收录 PDF：<https://backend.fetzer.org/sites/default/files/images/stories/pdf/selfmeasures/Attachment-OriginalAttachmentThreeCategoryMeasure.pdf>
- 其中 PDF 第 4-6 页含 `THE RELATIONSHIPS QUESTIONNAIRE (RQ)` 与题目文本。

理论来源：

- Bartholomew, K. & Horowitz, L. M. (1991). *Attachment styles among young adults: A test of a four-category model.*

当前可确认信息：

- 能公开找到量表文本。
- 公开资料能证明其学术来源与题目内容。
- 但我没有找到像 CC BY / CC BY-SA 这种对商业复用非常明确的官方授权声明。

合规判断：

- `不建议` 直接把 RQ 原文逐字作为商业网站正式题库。
- `可以` 把它作为理论框架和结果分类参考。
- `可以` 参考其四类型描述，自主重写成更口语化、更场景化的题项。

风险等级：

- 学术引用风险低
- 直接商用原文风险中等

### 2. ECR：Experiences in Close Relationships

定位：

- 成人依恋经典量表，36 题。
- 测量焦虑和回避两个维度。

来源概览：

- Fraley 量表索引页：<https://labs.psychology.illinois.edu/~rcfraley/measures/measures.html>
- 相关原始综述与说明页会指向 Brennan 等人的 1998 章节。

当前可确认信息：

- ECR 是公开发表的学术量表。
- 但相关核心章节由 Guilford Press 出版，Fraley 页面明确提示该章节受版权保护，不应未经许可复制。

Fraley 页面原意可概括为：

- 历史性章节仅供阅读参考，受 Guilford Press 版权保护，不应无许可复制。

来源：<https://labs.psychology.illinois.edu/~rcfraley/measures/measures.html>

合规判断：

- `不建议` 直接把 ECR 原始题项整套搬到商业网站。
- `适合` 用作理论与评分结构参考。

风险等级：

- 直接商用原文风险中高

### 3. ECR-R：Experiences in Close Relationships-Revised

定位：

- 36 题，成人依恋里非常常用。
- 仍然测“焦虑 / 回避”两维。

公开来源：

- 官方介绍与 FAQ：<https://labs.psychology.illinois.edu/~rcfraley/measures/ecrr.htm>
- 题项与评分页：<https://labs.psychology.illinois.edu/~rcfraley/measures/ecrritems.htm>

目前最关键的授权信息：

- 官方页面明确写明：
  - 非商业研究使用，无需联系作者申请许可
  - 商业用途，不得未经许可使用

来源：<https://labs.psychology.illinois.edu/~rcfraley/measures/ecrr.htm>

因此可得出明确判断：

- `不能直接用于商业网站正式上线`，除非你取得许可。
- `可以` 用于学术研究、内部验证、题库设计参考。

风险等级：

- 直接商用原文风险高

### 4. ECR-RS：Relationship Structures

定位：

- 更短，可测不同关系对象。
- 适合之后做“恋爱关系 / 父母关系 / 朋友关系”多场景扩展。

公开来源：

- 官方页：<https://labs.psychology.illinois.edu/~rcfraley/measures/relstructures.htm>

当前可确认信息：

- 官方页可确认其测量逻辑和使用背景。
- 本次未检索到比 ECR-R 更明确、更宽松的商业授权说明。

合规判断：

- `适合参考`
- 若用于商业产品，仍建议按“需单独核实许可”处理

风险等级：

- 中等

### 5. ECR-G-10：Experiences in Close Relationships Scale - German 10-Item Short Form

定位：

- 10 题短版，基于 ECR 路线。
- 适合做短测原型和结构参考。

公开来源：

- Open Test Archive 页面：<https://www.testarchiv.eu/de/test/9008624>

已确认信息：

- 页面明确标注：`Copyright AutorInnen; CC-BY-SA 4.0`
- 页面同时公开了 10 个德文题项、维度划分与计分方式

来源：<https://www.testarchiv.eu/de/test/9008624>

注意事项：

- 该量表是 `德文短版`
- 页面说明它是 Bochumer Bindungsfragebogen / ECR 的德文版本短式
- 即使页面本身许可明确，也不应把它简单视为“原始英文 ECR 全部自由商用”

合规判断：

- `适合` 作为开放许可示范样本、结构参考、数据建模参考
- 如果你未来考虑德语市场，可进一步评估其 CC BY-SA 传播义务
- 中文网站不建议直接把德文题项机翻上线

风险等级：

- 作为参考风险低
- 直接做中文商业题库风险中等

### 6. OpenScales

平台定位：

- 开放心理论表仓库，不是某一个量表
- 每个量表单独带 license 字段

公开来源：

- <https://openscales.net/>

已确认信息：

- 平台明确提示：所有量表按各自许可证提供
- 有些是公有领域，有些要求署名
- 商业场景必须逐个检查 `license field`

来源：<https://openscales.net/>

合规判断：

- `适合` 作为后续持续找量表的仓库入口
- `不适合` 在没核对单个量表 license 前直接使用

风险等级：

- 平台本身低
- 具体量表取决于各自许可证

## 四、推荐的可落地题库方案

### 方案 A：最稳妥，适合商业上线

做法：

1. 使用四类依恋理论框架。
2. 参考 RQ 的四类定义。
3. 参考 ECR/ECR-R 的二维结构。
4. 自主撰写一套中文原创题项。
5. 通过小样本测试校准“焦虑 / 回避”两维阈值。

建议题量：

- MVP：`12 题`
- 标准版：`16-24 题`

建议维度分布：

- 焦虑维度：6-12 题
- 回避维度：6-12 题

优点：

- 商业合规最好
- 可做品牌化语言风格
- 更适合中文互联网传播

缺点：

- 需要你自己做一轮文案与简单测量校准

### 方案 B：授权优先，尽量保留“量表血统”

做法：

1. 联系 ECR-R 或相关作者/权利方确认商业授权。
2. 如果拿到许可，按许可条件使用或改编。
3. 前台继续输出四类结果，后台保留二维分数。

优点：

- 学术背书最强

缺点：

- 流程慢
- 未必能顺利拿到适合互联网产品的授权

### 方案 C：开放量表混合改写

做法：

1. 以 Open Test Archive / OpenScales 中许可清晰的短量表为基础。
2. 只保留维度逻辑和场景方向。
3. 做中文原创改写与本地化。

优点：

- 合规相对友好
- 成本低于正式授权

缺点：

- 仍需逐条核验来源链路

## 五、版权与专利风险规避清单

### 版权风险

需要重点规避的不是“依恋理论”本身，而是这些受保护内容：

- 原始题项文本
- 原版说明语
- 原版评分表述
- 结果页大段解释文案
- 竞品网页中的结构化文案和视觉表达

建议做法：

1. 不直接抓取竞品题库。
2. 不整段照抄 RQ、ECR、ECR-R 原文。
3. 若参考公开量表，保留来源记录与许可截图。
4. 你自己写中文题项时，避免逐句直译。
5. 结果页文案全部原创。
6. 若使用开放许可量表，按许可证保留署名与相同方式共享义务。

### 商标与命名风险

建议：

- 可以写“基于依恋理论”
- 尽量不要把产品主标题直接命名为“ECR-R 官方测试”或“Relationship Questionnaire 官方版”
- 不要暗示你获得了原作者官方背书，除非确实有授权

### 专利风险

本次做了公开层面的初步检索，未发现成人依恋经典量表在公开结果中存在明显、常见的现行专利主张线索。  
但需要注意：

- 我这次做的是产品前期检索，不是正式法律检索
- “无明显专利结果”不等于“法律上绝对无风险”

对一般内容型测试网站来说，现实中的主要风险通常仍是：

1. 版权
2. 虚假宣传
3. 医疗/心理诊断暗示
4. 用户隐私与敏感信息收集

如果你要大规模商业投放，最好上线前让律师做一次正式审阅。

## 六、你这个四类结果页，建议怎么改

你给的样例图方向是对的，信息结构也比较完整，适合继续发展。  
为了更适合“依恋类型测试”产品，我建议基于当前结构做以下升级。

### 1. 顶部结果卡

当前已有：

- 类型名称
- 一句副标题

建议补充：

- 四类象限标签  
  例如：`低焦虑 / 低回避`
- 一个置信度或主导倾向提示  
  例如：`你的安全型倾向明显，但在高压力关系中会出现轻度焦虑反应`

这样能避免把人格说得过于绝对。

### 2. 得分分布卡

你现在展示的是四类百分比条形图，这适合传播。  
建议增加一层“解释来源”：

- 四类占比：给用户看结果
- 二维原始维度：给更想深入的人看

可以新增一张小卡片：

- 依恋焦虑：`中低`
- 依恋回避：`低`

这样结果会更可信，也更方便以后扩展成长建议。

### 3. 关于你的依恋类型

建议把这一段从“静态介绍”改成“场景化描述”，分成 3 段更有代入感：

- 在关系刚开始时，你通常怎样
- 在发生矛盾时，你通常怎样
- 在需要承诺或亲密时，你通常怎样

这样会比纯概念说明更像消费级产品。

### 4. 主要特征

建议保留，但不要只写优点。  
每种类型至少写三组内容：

- 优势
- 容易卡住的点
- 在高压关系中的常见反应

这会让结果更立体，避免“只是在贴标签”。

### 5. 成长建议

建议不要做成泛泛心灵鸡汤，而是给“可执行动作”：

- 情绪触发时先暂停 10 分钟再沟通
- 用“我感到……”替代“你总是……”
- 每周一次明确表达需求，而不是等待对方猜到

最好把建议拆成：

- 今天就能做
- 关系里持续练习
- 适合寻求咨询支持的情况

### 6. 页尾免责声明

建议强化但不吓人：

- 本结果用于自我探索与关系反思
- 不构成医学、心理诊断或治疗建议
- 若长期出现关系创伤、强烈焦虑、情绪失控，建议寻求专业支持
