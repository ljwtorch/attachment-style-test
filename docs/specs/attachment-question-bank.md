# 依恋测试题库设计说明

更新时间：2026-05-18

## 结论

当前仓库里旧版题库 `不符合` 现在的产品要求，原因有三个：

1. 旧版是 `40` 题，不是 `55` 题。
2. 旧版是 `5 点同意度量表`，不是“`1 个题干 + 4 个单选项`”。
3. 旧版没有把结果页需要的 `类型解析 / 主要特征 / 成长建议` 直接写进题库数据。

现在已经改成符合要求的新版本：

- 题库文件：[attachment-style-bank.v2.json](/Users/lijuwei/Documents/workspace/attachment-style-test/data/question-banks/attachment-style-bank.v2.json)
- 题库总量：`55` 题
- 每题形式：`1 个场景题干 + 4 个单选项`
- 每次作答：`随机抽取 38 题，不重复`
- 结果内容：内置 `安全型 / 焦虑型 / 回避型 / 混乱型` 的解析、特征和建议

## 数据结构

当前题库是按前端可直接消费的结构来组织的，核心字段有：

- `draw_policy`
- `styles`
- `scoring`
- `result_page_copy`
- `result_profiles`
- `questions`

### 抽题规则

- `mode`: `random_without_replacement`
- `draw_count`: `38`
- `required_answer_count`: `38`

也就是说，前端每次进入测试时，从 55 道母题里随机取 38 道，用户答满 38 道后再出结果。

## 计分逻辑

这版题库不再使用“非常同意/不同意”的量表方式，而是改成更贴近你截图的 `四选一行为选项`。

每道题的四个选项分别对应四类依恋倾向之一：

- `secure`
- `anxious`
- `avoidant`
- `fearful`

### 主结果

主结果直接用 `style_votes` 统计：

1. 用户每选一个选项，就给该选项对应的依恋类型 `+1`
2. 38 题答完后，四类票数换算成百分比
3. 票数最高的类型，作为主类型

这很适合做你第二张图里的“得分分布”卡片。

### 二维辅助信息

为了保留理论结构，题库里也保留了 `依恋焦虑` 和 `依恋回避` 的辅助维度积分：

- `secure` = 低焦虑、低回避
- `anxious` = 高焦虑、低回避
- `avoidant` = 低焦虑、高回避
- `fearful` = 高焦虑、高回避

它主要用于：

- 并列结果时做判定
- 后续做更细的结果解释
- 以后扩展出“二维坐标图”

## 结果页内容

题库里已经直接放进了结果页所需的四类内容：

- 类型名称
- 副标题
- 关于你的依恋类型
- 主要特征
- 成长建议

对应字段在 `result_profiles` 下，已经和你截图里的信息结构对齐。

## 使用建议

如果你按这套数据直接开发，推荐页面流程是：

1. 进入测试时随机抽取 38 题
2. 显示进度：`第 x 题 / 共 38 题`
3. 每题展示 4 个单选项
4. 提交后统计四类票数和百分比
5. 输出主类型 + 四类分布条
6. 渲染该类型的 `about`、`traits`、`advice`
7. 页尾显示免责声明

## 合规说明

这套题库仍然遵循之前的合规原则：

- 基于公开依恋理论创作
- 不直接照搬经典量表原题
- 结果用于自我探索，不做临床诊断承诺
