# Attachment Style Test

Language: English | [简体中文](./README.zh-CN.md)

This repository is an attachment style test project.
It is built to provide a real, runnable web experience for exploring common attachment patterns in close relationships.

## Purpose

- Help users reflect on how they usually respond to intimacy, distance, uncertainty, and emotional support in relationships
- Turn attachment-style question content and result interpretation into a usable product experience instead of a static concept
- Serve as a foundation for future expansion into a more complete testing product with richer flows and result feedback

## Note

This project is intended for self-reflection and relationship awareness only.
It is not a medical or clinical diagnostic tool.
